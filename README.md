## 👋 Welcome to TweakHeaven

TweakHeaven is an independent development project focused on
iOS modding, native applications, sideloading tools and
self-hosted solutions.

Our goal is to build reliable, privacy-conscious and
user-friendly tools for the iOS community.

## 🚀 Our Projects

### 🔔 WatusiPush

![Status](https://img.shields.io/badge/Status-Private_Alpha-orange)

Native APNs push notifications for sideloaded WhatsApp
with Watusi.

**Current features:**

- Native Apple Push Notifications (APNs)
- Automatic APNs token synchronization
- Contact profile pictures
- Group profile pictures
- Tap-to-Chat
- Notifications when WhatsApp is completely closed
- Self-hosted Docker backend
- Dedicated Notification Service Extension
- No jailbreak required
- No Background Audio required

An open-source release is planned.

### 📦 Watusi Patcher

![Status](https://img.shields.io/badge/Status-Private_Alpha-orange)

A native iOS application designed to simplify IPA patching,
signing and installation directly on your device.

**Current features:**

- Native SwiftUI interface
- On-device IPA patching
- Dylib integration
- Notification Service Extension integration
- Local certificate management
- Provisioning profile validation
- Update protection
- On-device signing and installation
